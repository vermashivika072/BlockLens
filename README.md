# 🛡️ CertiChain: AI-Powered Blockchain Forensic Suite

### *The Future of Document Integrity & Forgery Detection*

---

## 🚀 Overview
CertiChain is a high-performance, automated document verification system that combines **Deep Learning Forensics** with **Blockchain Immutability**. It doesn't just check if a certificate is real; it analyzes the "Digital DNA" of the document to pinpoint exactly where and how it was tampered with.

## ✨ Key Features

### 🤖 AI Innovate + Automation
* **Advanced AI Assistant:** A context-aware chatbot powered by **Gemini API** that explains forensic results to users in natural language.
* **Complete AI Report Analysis:** Automated summarization of complex forensic data into human-readable executive reports.
* **Auto-Decision System:** Intelligent classification of documents as **Valid**, **Suspicious**, or **Fake** based on multi-factor consensus.
* **Batch Processing:** Ability to upload and verify multiple certificates simultaneously using backend queues.

### 🔍 Forensic Intelligence (ML/DL)
* **Error Level Analysis (ELA):** Detects digital manipulation by analyzing compression inconsistencies.
* **Deep Learning (CNN):** A Convolutional Neural Network trained to distinguish between natural image noise and malicious forgery.
* **Forensic Heatmaps:** Visual representation of tampered areas, allowing users to see exactly what was changed.

### ⛓️ Blockchain Security
* **Immutable Hashing:** Generates a unique SHA-256 fingerprint for every document.
* **Decentralized Verification:** Cross-references hashes with the **Polygon/Ethereum** ledger to ensure 100% data integrity.

### 🎨 Next-Gen UI/UX
* **3D Landing Page:** Immersive experience using **Three.js** featuring interactive 3D certificate models and floating assets.
* **User Vault:** Secure dashboard to manage personal certificates and view verification history stored in **MongoDB**.

## 🔬 The AI Forensic Advantage
Unlike traditional verification, our engine performs a multi-layer deep-scan:
* **Pixel Analysis:** Identifying inconsistencies in metadata and error levels.
* **Textual Integrity:** Using OCR to detect font mismatches and logical inconsistencies in data.
* **Consensus Logic:** Combining Blockchain proof with AI probability scores to eliminate False Positives.
